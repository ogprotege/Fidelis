# UI Polish Pass (v1.22.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the six approved UI-polish fixes (spec: `docs/superpowers/specs/2026-07-18-ui-polish-design.md`) as release v1.22.1, each harness-pinned.

**Architecture:** Presentation/copy-only edits inside the existing design system (tokens, two-accent rule, six-card rule). One new optional prop on `ReadingText`; one new CSS class; no behavior changes to any setting. New harness section §39 guards all of it, written red-first in Task 1.

**Tech Stack:** React 19 + TS (strict) + Vite, custom `tsx` harness (`scripts/test-data.ts`), Playwright e2e.

## Global Constraints

- Design tokens only; **no raw hex** in `src/` (liturgical-content colors and the share-card canvas are the only existing exceptions — do not add more).
- Two-accent rule: `--purple` acts, `--gold` honors. No new Today card (six-card rule).
- No emoji in `.tsx`. `Sheet.tsx` remains the only dialog primitive. No new routes.
- TS strict with `noUnusedLocals`/`noUnusedParameters`; eslint must stay clean.
- Every task ends green: `npx tsx scripts/test-data.ts` — and the whole suite green, not just the new checks.
- Commits use house style (`fix:` / `feat:` / `test:` / `chore:` / `docs:`).
- Work happens on branch `claude/v1.22.1-ui-polish`, cut from `claude/v1.22.0-enrichment` (PR #69's branch — v1.22.1 builds on it). PR targets `main`; its diff shrinks to v1.22.1-only once #69 merges.
